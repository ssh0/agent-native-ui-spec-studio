# スタジオ実機確認

ブラウザ自動確認は環境制約のためこの作業では実施していません。キャプテンが実機で確認する場合は、リポジトリ直下で次を実行します。

```bash
AUTH_DISABLED=true pnpm dev -- --port 4173
```

1920×1080のブラウザで `http://localhost:4173/spec` を開き、次を順に確認します。

1. 左側に「データ・用語 → 業務フロー → ユースケース → 画面・状態 → 画面内アクション」の5段階が並び、現在段階、件数、未定義状態が読める。
2. 中央の対象一覧と詳細領域が独立してスクロールし、右側に検証・レビュー・履歴が同時に収まる。ヘッダーの保存状態と保存操作が常に見える。
3. 各段階を切り替え、空配列の段階でも「未定義」と追加導線が表示される。既存例ではデータ、フロー、ユースケースの参照が詳細に表示される。
4. 画面・状態で定義、ワイヤーフレーム、画面遷移図、画面状態図を切り替え、Mermaidが描画される。ユースケースでは分岐と例外が図に含まれる。
5. 「Mermaidを試作」でソース編集と「仕様から再生成」が動作する。試作ソースはYAMLへ自動保存されないことが表示される。
6. 「この段階を編集」「編集内容を反映」「YAMLを直接編集」「仕様を保存」を順に確認する。YAML構文・参照エラー、未保存変更、保存競合、再試行の表示が日本語で読める。
7. レビュー欄でコメントを入力し、保存済みかつ検証済みの仕様を承認／修正依頼できる。履歴に対象段階、日時、コメント、文書ハッシュが残る。
8. 日本語ラベルの折返し、表の列幅、ボタンのフォーカス、読み込み中・空状態・エラー状態を確認する。情報が画面外へ過度に流れず、段階ナビと右インスペクターの境界が判別できる。

狭い幅では段階ナビが横並び、検証欄が中央の下段に移るレスポンシブ挙動も確認します。
