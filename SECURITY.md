# Security policy

Please do not disclose a suspected vulnerability or exposed secret in a public issue, pull request, discussion, or screenshot. Use GitHub's private vulnerability reporting for this repository when available. If that option is unavailable, contact the repository owner through a private GitHub channel and share only enough detail to arrange a secure report.

Include the affected version or commit, a minimal reproduction using synthetic data, and the expected impact. Do not include real credentials, customer information, private specifications, or chat logs. The maintainer will coordinate triage and disclosure through the private channel.
